# GroupDrawProgram

학생 명단의 성별과 함께/분리 조건을 이용하는 정적 모둠 배치 도구입니다.
제품 로직과 화면은 `index.html`에 있으며 GitHub Pages는 `main:/`을 게시합니다.

- **남녀 골고루:** 모둠 정원을 지키며 전체 명단의 성비를 가능한 한 고르게 나눕니다. 성별별 인원이 나누어떨어지지 않을 때는 정원에 비례한 몫을 사용합니다.
- **같은 성별끼리:** 남학생과 여학생 모둠을 따로 구성합니다.
- **소수 성별 1명씩:** 모둠마다 정확히 한 명인지 확인합니다. 선택한 모둠 수와 소수 성별 인원이 다르면 남은 미충족 조건을 표시하며, 명시적으로 선택한 모둠 수를 몰래 줄이지 않습니다. 남녀 인원이 같으면 남학생을 기준으로 확인합니다.
- **성별 상관없이:** 성별 조건 없이 무작위로 배치합니다. 별도로 선택한 남녀 2명 이상 조건은 계속 검사합니다.

함께/분리 필수 조건, 성별 조건, 지난 짝 피하기 순으로 후보를 비교합니다.
탐색은 최대 8,000회이며, 완전 충족 후보를 찾지 못하면 남은 조건을 표시합니다.
모든 가능한 배치를 검증하는 완전 탐색이나 최적성 증명으로 안내하지 않습니다.
명단·제한 조건·지난 짝의 기존 브라우저 저장 키와 파일 형식은 유지합니다.

## 회귀 검사

Node.js의 기본 테스트 실행기만 사용하며 별도 설치가 필요하지 않습니다.

```sh
node --test tests/grouping.test.mjs
```

실제 `index.html`의 로직을 결정적 난수와 가짜 React/브라우저 환경에서 실행합니다.
실제 명단, 브라우저 저장소, 네트워크나 GitHub 계정을 사용하지 않습니다.
